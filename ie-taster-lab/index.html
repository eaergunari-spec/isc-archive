Stage 3 · Optimize

How do we know what is best?

Code Moment 1
Your manual plan may be good. But can you prove that no better feasible allocation exists?

The short Python code checks every feasible way to allocate 20 couriers. Copy it into a Python cell if your instructor asks you to run it.

forecast = [32, 28, 24, 16]
rate = [4, 3, 5, 2]

best_score = -1
best_plan = None

for a in range(21):
    for b in range(21-a):
        for c in range(21-a-b):
            d = 20-a-b-c
            plan = [a, b, c, d]
            served = sum(
                min(forecast[i], rate[i]*plan[i])
                for i in range(4)
            )
            if served > best_score:
                best_score = served
                best_plan = plan

print(best_plan, best_score)
Throughput-maximizing plan: [8, 7, 5, 0] → 77 orders served

Mathematically correct. Operationally uncomfortable: Beşiktaş receives zero couriers.

Is the “optimal” solution automatically a good decision?

Stage 6 · Simulate

One forecast is not one future

Code Moment 2

Generate 1,000 plausible evenings around the same forecast. The same decision now produces a distribution of outcomes, not one number.

Average served—
10th percentile—
Worst evening—
Best evening—
import numpy as np
import matplotlib.pyplot as plt

forecast = np.array([32, 28, 24, 16])
rate = np.array([4, 3, 5, 2])
allocation = np.array([6, 5, 5, 4])

future_demand = np.random.poisson(
    forecast, size=(1000, 4)
)

capacity = allocation * rate
served = np.minimum(future_demand, capacity)
total_served = served.sum(axis=1)

print("Average:", total_served.mean())
print("10th percentile:",
      np.percentile(total_served, 10))

plt.hist(total_served, bins=15)
plt.show()
